# ADR-001: Вибір моделі для текстових ембеддингів


## Контекст

Стек abox використовує Qdrant як векторну базу даних для семантичного пошуку. Retrieval-agent індексує Kubernetes-маніфести і відповідає на запити типу "що конфігурує X" через vector search. Для цього необхідна embedding-модель, яка:

- Працює локально (без зовнішніх API)
- Запускається в кластері з обмеженими ресурсами (GitHub Codespaces: 4–8 CPU, 8–16 GB RAM)
- Сумісна з llama.cpp або Ollama для локального інференсу
- Підтримує достатній контекст для маніфестів (YAML-файли бувають об'ємними)

---

## Розглянуті варіанти

### 1. `nomic-ai/nomic-embed-text-v1.5` (обрано)

| Параметр | Значення |
|---|---|
| Розмір моделі | ~275 MB (GGUF Q4) |
| Розмірність вектора | 768 |
| Контекст | 8 192 токенів |
| Формат | GGUF — нативна підтримка llama.cpp |
| Ліцензія | Apache 2.0 |

**Переваги:**
- Нативна підтримка llama.cpp без конвертації
- Великий контекст (8k) — вміщує цілі YAML-маніфести
- Матерований для English + code, добре працює з k8s-маніфестами
- Ефективне використання RAM завдяки memory-mapped GGUF

**Недоліки:**
- Більший розмір порівняно з MiniLM

---

### 2. `sentence-transformers/all-MiniLM-L6-v2`

| Параметр | Значення |
|---|---|
| Розмір моделі | ~80 MB |
| Розмірність вектора | 384 |
| Контекст | 256 токенів |

**Переваги:** Дуже легка, швидка.  
**Недоліки:** Контекст 256 токенів — занадто малий для Kubernetes YAML. Потрібне агресивне чанкування, що погіршує якість retrieval. Не підтримується llama.cpp нативно.

---

### 3. `BAAI/bge-small-en-v1.5`

| Параметр | Значення |
|---|---|
| Розмір моделі | ~120 MB |
| Розмірність вектора | 384 |
| Контекст | 512 токенів |

**Переваги:** Якісна модель для англійського тексту.  
**Недоліки:** Контекст 512 токенів — недостатній. Немає GGUF-версії для llama.cpp.

---

## Рішення

Обрано **`nomic-ai/nomic-embed-text-v1.5`** у форматі GGUF для запуску через llama.cpp.

**Обґрунтування:**
- Єдина з розглянутих, що нативно підтримується llama.cpp у форматі GGUF
- Контекст 8k дозволяє індексувати маніфести без розбиття на шматки
- Вписується в ресурсні обмеження Codespaces (500m CPU, 512Mi RAM)
- Однаковий runtime (llama.cpp) для embedding і LLM-інференсу — спрощує операційну модель

---

## Наслідки

- Embedding-сервіс запускається як окремий Deployment у namespace `llama-cpp`
- Endpoint: `http://llama-cpp.llama-cpp.svc/v1/embeddings`
- Розмірність векторів у Qdrant колекції: **768**
- При переході на іншу модель — необхідне повторне індексування колекції
